## 5. 关键实现说明

1. **测试工具复用**：使用 `tests/api/common.rs` 提供的 fixtures（`test_state`, `register_user`, `login_user` 等）
2. **请求构造**：使用 `json_request` / `empty_request` 构造 HTTP 请求
3. **响应解析**：使用 `read_json` / `read_text` 解析响应
4. **数据隔离**：每个测试创建独立用户（`unique_phone_username()`）
