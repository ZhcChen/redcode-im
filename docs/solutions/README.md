# 解决方案沉淀目录

本目录用于存放轻工作流 `compound` 阶段产出的解决方案、问题复盘与经验沉淀文档。
在 Codex 中也可通过 `ce:compound` 进入该阶段。

## 约定

- 按主题或问题类型分子目录组织
- `TEMPLATE.md` 只作结构参考，不写入真实任务内容
- 解决方案文档应尽量包含问题背景、根因、处理方式、验证方法与复用建议
- 只沉淀可复用决策、复发坑点、稳定排查路径或长期模式，不原样保存一次性执行日志

## 与其他目录的关系

- `docs/brainstorms/` 关注需求与方向
- `docs/plans/` 关注实施步骤
- `docs/reviews/` 关注审查与验证结论
- `docs/solutions/` 关注已验证结论与长期复用知识
