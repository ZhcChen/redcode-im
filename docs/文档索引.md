## 🚀 快速开始

### 环境要求
- Rust 1.75+
- Node.js 18+ / Bun
- PostgreSQL 15+
- Redis 7+

### 启动后端
```bash
cd backend
cargo run
```

### 启动桌面端
```bash
cd desktop
bun install
bun run tauri dev
```

### 启动移动端
```bash
cd frontend
flutter run
```

### 启动管理后台
```bash
cd admin
bun install
bun run dev
```

详细安装步骤请查看 [项目 README](../README.md)。
