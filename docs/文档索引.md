# RedCode IM - 即时通讯系统

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Rust](https://img.shields.io/badge/Rust-1.75+-orange.svg)](https://www.rust-lang.org/)
[![TypeScript](https://img.shields.io/badge/TypeScript-5.0+-blue.svg)](https://www.typescriptlang.org/)

RedCode IM 是一个现代化的即时通讯系统，采用微服务架构设计，支持私聊、群聊、文件传输、消息搜索等完整功能。

## 🔄 最新进度（2025-11-08）

- **后端依赖全面升级** ✅：所有依赖升级到最新稳定版本
  - Axum 0.7 → 0.8.6
  - SQLx 0.7 → 0.8.6
  - Redis 0.24 → 0.32.7
  - argon2 0.6.0-rc.2 → 0.5.3 (修复 RC 版本问题)
  - 详见[后端依赖升级记录](报告/后端依赖升级_2025-11-08.md)

- **桌面端头像直传稳定**：TypeScript 端补充 `client_debug` 日志、Rust HTTP 透传 `injectToken/forceStreaming`，并内置 `VITE_AUTO_UPLOAD_TEST` 自动化脚本，可在 30s 内完成登录+上传+日志采集（详见 `docs/文件上传/文件上传排障.md`）。

- **数据库结构统一**：`backend/sql/all.sql` 已合并所有迁移脚本，一次执行即可创建 26 张表；同时修复 `UserStore::update_user` 返回列缺失导致的 SQLx `ColumnNotFound`。

- **日志与排障策略**：桌面端启动时会轮换 `app.log`，头像上传失败可直接比对 `avatarUploadPrepared` 与 `HTTP_REQUEST` 段落，减少反复复现成本。

- **项目评估完成**：完成全面的项目分析和进度评估，详见[项目现状评估报告](报告/项目现状评估报告_2025-11-08.md)。

## ✨ 特性

- 🚀 **高性能**: 基于 Rust + Axum 构建，异步处理，高并发支持
- 💬 **实时通讯**: WebSocket 实时消息推送
- 👥 **群组管理**: 完整的群组管理功能，包括权限控制、成员管理
- 🔍 **消息搜索**: 强大的消息搜索功能，支持全文检索
- 📁 **文件传输**: 支持图片、文档、音频、视频等多种文件类型
- 🔐 **安全认证**: JWT Token 认证，密码加密存储
- 📊 **监控统计**: 完整的系统监控和数据统计
- 🌍 **多平台**: 支持桌面端（Vue 3 + Tauri）、移动端（Flutter）、Web端（Nuxt 3）

## 🏗️ 技术架构

### 后端 (backend)
- **语言**: Rust 1.75+
- **框架**: Axum 0.8.6 (✅ 最新稳定版)
- **异步运行时**: Tokio 1.44
- **数据库**: PostgreSQL 15 (SQLx 0.8.6, 26 张表)
- **缓存**: Redis 7 (redis 0.32.7, Cluster 模式)
- **WebSocket**: 支持实时消息推送（JSON + Protocol Buffers 0.14）
- **认证**: JWT 9.3 + bcrypt 0.16 + argon2 0.5.3
- **HTTP 客户端**: reqwest 0.12
- **文件存储**: 多存储提供商支持（本地、COS、S3）

### 桌面端 (desktop)
- **语言**: TypeScript 5.0+
- **框架**: Vue 3
- **桌面应用**: Tauri 2.0
- **构建工具**: Vite
- **状态管理**: Vuex
- **环境**: 支持开发/测试/生产三环境

### 移动端 (frontend)
- **语言**: Dart
- **框架**: Flutter 3.9+
- **平台支持**: iOS、Android、Web、macOS、Windows、Linux

### 管理后台 (admin)
- **语言**: TypeScript
- **框架**: Vue 3
- **UI 库**: Arco Design Pro
- **构建工具**: Vite
- **状态管理**: Pinia

## 🚀 快速开始

### 环境要求
- Rust 1.75+
- Node.js 18+ / Bun
- PostgreSQL 15+
- Redis 7+

### 启动后端
```bash
cd backend
cargo run
```

### 启动桌面端
```bash
cd desktop
bun install
bun run tauri dev
```

### 启动移动端
```bash
cd frontend
flutter run
```

### 启动管理后台
```bash
cd admin
bun install
bun run dev
```

详细安装步骤请查看 [项目 README](../README.md)。
