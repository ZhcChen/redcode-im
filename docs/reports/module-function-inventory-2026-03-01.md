# RedCode IM 模块功能清单（2026-03-01）

> 范围：`backend`、`admin`、`frontend`、`desktop`、`website`
> 
> 目的：作为“从 0 重建测试与验收”的功能基线，后续所有测试用例与验收场景均以本清单和矩阵为追溯源。

## 1. Backend（Rust / Axum）

### 1.1 认证与鉴权
- 用户注册、密码登录、短信登录、OAuth 登录（Google/Apple）
- Token 刷新
- 管理员登录与刷新
- 当前登录用户信息查询

### 1.2 用户中心
- 用户资料查询与更新
- 密码修改与短信重置
- 头像上传提交与下载地址获取
- 用户搜索与按 ID 查询

### 1.3 社交关系
- 好友申请、处理申请、好友列表
- 备注设置与好友删除
- 从好友关系发起单聊

### 1.4 聊天与群组
- 会话列表、会话删除
- 房间创建、入群、退群、成员管理
- 群管理员、群设置、群公告/规则（由对应 handler 支持）

### 1.5 消息能力
- 发送消息、编辑、删除、转发、引用
- 已读回执与未读计数
- 消息反应（reaction）
- 消息搜索

### 1.6 文件与上传
- 普通上传与分片上传
- 上传策略
- 头像/聊天附件对象存储访问
- 上传审核（腾讯 CI）与清理任务

### 1.7 业务支撑
- 反馈提交、举报提交
- 客户端版本管理（最新版本、热更新、下载地址）
- 推送设备注册/注销与 Push 队列
- IP 地理位置解析

### 1.8 管理后台 API
- Dashboard 统计接口
- 用户/角色/权限/管理员管理
- 文件、聊天记录、反馈、举报管理
- 系统设置（基础、上传、存储、Push、日志）

### 1.9 实时与系统
- WebSocket 连接与消息推送
- Redis 会话与缓存
- 健康检查与就绪检查

## 2. Admin（Vue 3）

### 2.1 登录与权限
- 管理员登录
- 路由守卫与权限控制

### 2.2 Dashboard
- 工作台数据
- 监控数据与统计卡片

### 2.3 用户与内容治理
- 用户管理
- 聊天记录管理
- 反馈/举报管理

### 2.4 运营与审计
- 系统日志
- Push 日志
- 文件审核任务与处理

### 2.5 系统配置
- 通用配置（应用名、验证码策略）
- 协议配置（用户协议、隐私协议）
- 存储、上传策略、Push、IP 地理配置

### 2.6 版本管理
- 版本列表与新增/更新
- 热更新与安装包配置

## 3. Frontend（Flutter）

### 3.1 启动链路
- 启动页初始化
- 版本检查与更新入口

### 3.2 账号体系
- 登录、注册、登出
- 会话恢复

### 3.3 首页与导航
- 主框架与底部导航
- 会话/联系人/设置入口

### 3.4 聊天核心
- 会话消息列表
- 文本与附件发送
- 群聊交互

### 3.5 联系人与社交
- 联系人列表
- 好友申请与处理

### 3.6 扩展能力
- 发现页
- 表情包管理
- 设置与反馈

## 4. Desktop（Vue 3 + Tauri）

### 4.1 账号与登录
- 登录页面与账号状态管理
- 多账号本地保存

### 4.2 聊天与联系人
- Chat 视图、Contact 视图
- 消息发送、搜索、群组操作

### 4.3 设置与协议
- 通用设置页面
- 隐私协议页面
- 下载目录与系统交互

### 4.4 桌面增强能力
- Tauri 原生能力（通知、剪贴板、文件路径）
- WebSocket 客户端
- 版本更新与升级流程

## 5. Website（Nuxt）

### 5.1 落地页展示
- 产品卖点与功能介绍
- 多端下载模块

### 5.2 动态版本联动
- 根据 `platform + channel` 查询最新版本
- 渲染版本号与可用状态

### 5.3 下载地址获取
- 通过后端接口获取临时下载链接
- 商店链接与安装包下载兼容

### 5.4 平台识别
- 用户设备平台识别
- 主下载按钮的平台优先策略

## 6. 外部依赖（需本地可模拟）

- Tencent COS（对象、分片、CORS）
- Tencent CI（审核提交/查询）
- Google OAuth/JWKS
- Apple JWKS
- FCM Send + Google OAuth Token
- IPInfo

> 当前已在 `tests/mocks/external` 落地统一模拟服务，并在测试栈注入相关环境变量。
