## 一、项目概述

RedCode IM 是现代化即时通讯系统，包含：

- 后端：Rust（Axum + SQLx + Redis）
- 移动端：Flutter
- 桌面端：Vue 3 + Tauri
- 管理后台：Vue 3 + Arco Design

文档统一入口：`docs/index.md`
