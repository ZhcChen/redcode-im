# U10 E2EE U7-C SBOM 与许可证/漏洞检查报告

## 结论

Rust（`api/`、`e2ee-core/`）与前端（`h5-app/`、`admin/`）均以 lockfile
锁定依赖，可生成可重放的 SBOM 清单；协议核心 OpenMLS 0.8.1 为 MIT 许可证
（`e2ee-core/Cargo.lock` 精确锁定）。许可证批量核验与漏洞扫描尚未接入 CI，
按 U7 发布约束记为 **No-Go 阻断项**，不作为“已通过”宣称。

## 依赖清单与生成入口

| 端 | 锁文件 | 包数量（`[[package]]`） | 直接依赖 | 生成命令 |
| --- | --- | --- | --- | --- |
| API | `api/Cargo.lock` | 445（唯一 399） | `api/Cargo.toml` | `cargo metadata --locked --format-version 1` |
| E2EE 协议核心 | `e2ee-core/Cargo.lock` | 193（唯一 183） | `e2ee-core/Cargo.toml`（OpenMLS 0.8.1 精确锁定） | 同上 |
| H5 App | `h5-app/bun.lock` | Bun lockfile（含传递依赖） | `h5-app/package.json`（17 个直接依赖） | `bun pm ls --all` / `bun install --frozen-lockfile` |
| Admin | `admin/pnpm-lock.yaml` | pnpm lockfile（含传递依赖） | `admin/package.json`（60 个直接依赖） | `pnpm list --depth Infinity` |

权威 SBOM 以各端 lockfile 为准；上述生成命令用于导出可重放清单。Rust 清单
导出示例：

```bash
cd api && cargo metadata --locked --format-version 1 > sbom-api.json
cd e2ee-core && cargo metadata --locked --format-version 1 > sbom-e2ee-core.json
```

## 许可证核验现状

- 已人工确认：E2EE 协议核心 OpenMLS 0.8.1 及其
  `openmls_basic_credential` / `openmls_memory_storage` /
  `openmls_rust_crypto` / `openmls_traits` 版本精确锁定，许可证 MIT
  （`docs/plans/2026-08-04-001-feat-u10-e2ee-release-gate-plan.md` KTD1）。
- 未完成：对 `api/Cargo.lock` 445 个 crate 与 h5/admin 传递依赖做批量许可证
  白名单核验。工具入口：
  - Rust：`cargo install cargo-deny` 后 `cargo deny check licenses`
  - H5（Bun）：`bun pm licenses` / `license-checker`
  - Admin（pnpm）：`pnpm licenses list` / `pnpm dlx license-checker`
- 结论：许可证批量核验未完成，属于 U7 No-Go 阻断项；发布前须产出
  deny 白名单与全量核验报告。

## 漏洞扫描现状

- 未配置：仓库与 CI 未接入 Cargo Advisory / npm 生态漏洞扫描。
- 工具入口：
  - Rust：`cargo install cargo-audit` 后 `cargo audit`（基于
    RustSec Advisory Database，`api/` 与 `e2ee-core/` 分别执行）
  - H5：`bun audit`（基于 npm 审计数据）
  - Admin：`pnpm audit`
  - 统一入口候选：`osv-scanner scan --lockfile ...`
- 结论：CI 漏洞扫描未配置，属于 U7 No-Go 阻断项；发布前须接入并保留
  最近一次全量扫描结果。

## 与 R14/R15 的关系

- R14 数据面扫描由 `api/tests/e2ee_marker_scan.rs`（U7-A）与
  `scripts/scan-e2ee-log-denylist.sh`（U7-B）覆盖。
- 本报告提供“依赖是谁、许可证是否允许、漏洞是否已知”的可追溯入口，补齐
  发布门禁中的供应链维度；三份阻断项（许可证核验、漏洞扫描、生产演练）在
  U7-F 审查报告中统一裁决。
