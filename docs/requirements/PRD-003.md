**目标**: 将后端 Rust 代码测试覆盖率从约 50% 提升至 70%

**关联文档**:

3. **WebSocket 测试**: 需要 tokio-tungstenite 客户端
4. **测试隔离**: 继续使用 unique_phone_username() 模式
