- 未完成：`desktop/src/components` 仍保留原有业务组件，尚未按照迁移范围收敛。

## 重点待办
- 已完成：系统、好友 API 已接入 Rust 后端 REST 接口，聊天列表和消息拉取初步对接 `/chats`、`/rooms/:id/messages`，旧接口与依赖已替换为内部映射。
- 已完成：文件上传能力调整为仅支持头像快捷通道，其余上传场景暂时返回未实现提示。
- 待继续：补齐群设置、置顶、免打扰、已读回执等功能所依赖的后端接口或在前端增加显式降级提示。
- 待继续：完善消息发送（图片/语音/文件）与 WebSocket 读取状态同步，统一使用新的 `MessageApi`。
- 待继续：调整 Vuex Store 与页面逻辑，按新接口返回的数据模型彻底重构联系人、聊天面板及消息渲染，移除旧字段依赖。
- 待继续：统一构建与测试脚本，补充 `uv run python -m pytest` 等命令并更新 CI。
- 待继续：清理不再支持的业务模块（账户流水、红包、朋友圈、音乐、AI 等），同步更新组件目录与路由。

## 风险与关注点
- **接口改造范围大**：旧接口与新 REST 接口差异显著，需要逐模块验证请求与数据模型，防止遗漏。
- **实时能力空窗**：尚未对接 WebSocket，会导致桌面端缺乏消息实时性，需要优先落地。
- **测试缺口**：缺少自动化测试，迁移完成后必须补齐 Python 端到端脚本与回归清单。
- **功能取舍需确认**：被下线的旧功能需同步设计与产品，避免用户残留入口或数据。

4. 完成组件与路由清理，更新文档与发布脚本，确保桌面端与 `frontend` 一致对接。
