# 需求与方向讨论目录

本目录用于存放轻工作流 `brainstorm` 阶段的需求讨论、方向分析与方案收敛文档。
在 Codex 中也可通过 `ce:brainstorm` 进入该阶段。

## 约定

- 文件命名：`YYYY-MM-DD-<topic>-design.md`
- `TEMPLATE.md` 只作结构参考，不写入真实任务内容
- 内容重点：背景、目标、范围、方案比较、风险与验收标准
- 需求已经清晰时，不强制创建 brainstorm 文档，可直接进入 `docs/plans/`

## 与其他目录的关系

- 需求澄清与方案讨论先写入本目录
- 进入可执行阶段后，在 `docs/plans/` 中生成实施计划
- 重要改动完成后，可在 `docs/reviews/` 保留审查与验证记录
- 任务落地后的稳定经验，可沉淀到 `docs/solutions/`
