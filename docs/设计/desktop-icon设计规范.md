# Desktop 模块 Icon 设计规范

> 版本：v1.0  
> 适用范围：`desktop/src/assets/image` 目录下的所有功能性图标（emoji、file、voice 等）

## 1. 基本尺寸

- 统一使用 `24 × 24` 像素画布：`width="24" height="24" viewBox="0 0 24 24"`。
- 在界面中通过 `.action-icon { width: 24px; height: 24px; }` 进行展示。
- 图形需在视图中**水平垂直居中**，避免视觉偏上或偏下。

## 2. 颜色规范

- Desktop 输入区及置顶相关图标统一使用**中性灰**：
  - 颜色值：`#666666`
- 场景说明：
  - 表情图标：填充 + 描边均为 `#666666`。
  - 文件图标：描边为 `#666666`（填充可根据需要保持浅灰或白色）。
  - 语音图标：填充与描边为 `#666666`。
  - 置顶消息 Banner 右侧图标：描边为 `#666666`。

## 3. 线条粗细（Stroke）

- 建议描边宽度范围：`0.5 ~ 2`，根据具体图形在 24px 尺寸下的视觉效果微调。
- 当前约定：
  - 表情图标（emoji）：`stroke-width="0.5"`，避免轮廓过粗导致“发胖”感。
  - 文件图标（file）：`stroke-width="2"`。
  - 语音图标（voice）：主要轮廓线接近 `2`。
- 如需在同一图标内部使用不同粗细，应有明确的层级含义，并在设计评审时确认。

## 4. SVG 编写规范

- 所有 SVG 文件应满足：
  - `fill="none"` 或明确设置填充色；
  - 无多余的 `transform`、隐藏路径或未使用的 `defs`；
  - 路径数量控制在合理范围内，避免过度复杂。
- 示例（表情图标）：

```svg
<svg width="24" height="24" viewBox="0 0 24 24" fill="none" xmlns="http://www.w3.org/2000/svg">
  <path
    d="..."
    fill="#666666"
    stroke="#666666"
    stroke-width="2"
  />
</svg>
```

## 5. 使用约定

- 输入框左侧操作区（表情、文件、语音）图标必须：
  - 尺寸为 24px；
  - 使用 `#666666`；
  - 悬停效果通过透明度或轻微缩放处理，不改变颜色。
- 置顶消息相关图标（Banner 右侧 icon、置顶消息抽屉内 icon）需与输入区图标保持颜色与线条一致。

## 6. 变更流程

1. 新增或修改 Desktop 图标前，先查阅本规范并复用已有样式。
2. 修改 SVG 后：
   - 在 `desktop` 目录执行 `bun run type-check` 确认构建无误；
   - 手动在界面中检查表情、文件、语音及置顶图标的对齐与颜色效果。
3. 如有新的颜色或尺寸方案，需先在设计层面评审并更新本文件，再在代码中落地。
