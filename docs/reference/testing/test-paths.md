# 移动端 E2E 自动化测试路径

## 概述

本文档定义移动端 IM 应用的自动化测试路径，基于用户核心旅程设计，确保测试覆盖关键业务场景。

## 测试路径依赖图

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                              应用启动                                        │
└─────────────────────────────┬───────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│                       J1: 新用户注册旅程                                     │
│  启动 → 注册 → 完善资料 → 进入主页                                           │
└─────────────────────────────┬───────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│                       J2: 用户登录旅程                                       │
│  启动 → 密码登录/验证码登录 → 进入主页                                       │
└─────────────────────────────┬───────────────────────────────────────────────┘
                              │
            ┌─────────────────┼─────────────────┬─────────────────┐
            ▼                 ▼                 ▼                 ▼
┌───────────────────┐ ┌───────────────┐ ┌───────────────┐ ┌───────────────┐
│  J3: 添加好友旅程  │ │ J4: 私聊旅程   │ │ J5: 群聊旅程   │ │ J6: 设置旅程   │
│  搜索→发送申请    │ │ 选择→聊天→发送 │ │ 创建→管理→聊天 │ │ 个人资料→退出 │
└───────────────────┘ └───────────────┘ └───────────────┘ └───────────────┘
```

## 一、用户核心旅程 (User Journeys)

### J1: 新用户注册旅程

**目标**: 验证新用户可以成功注册并进入应用

| 步骤 | 操作 | 预期结果 | 优先级 |
|------|------|----------|--------|
| 1 | 启动应用 | 显示登录页面 | P0 |
| 2 | 点击「注册账号」 | 跳转到注册页面 | P0 |
| 3 | 输入手机号 | 输入框正常 | P0 |
| 4 | 获取验证码 | 显示倒计时 | P0 |
| 5 | 输入验证码 | 验证通过 | P0 |
| 6 | 设置密码 | 密码强度提示 | P0 |
| 7 | 勾选协议 | 协议勾选成功 | P0 |
| 8 | 点击注册 | 注册成功，进入主页 | P0 |

**测试路径**:
```
PATH: J1-001
前置: 无
步骤: 启动 → 注册页 → 填写信息 → 注册成功 → 主页
覆盖用例: AUTH-010, AUTH-011
```

## 四、测试执行策略

### 1. 冒烟测试 (Smoke Test)

**触发条件**: 每次 PR 合并到 main/develop

**执行命令**:
```bash
cd frontend
patrol test --target integration_test/smoke_test.dart
```

**测试文件结构**:
```
integration_test/
├── smoke_test.dart          # P0 冒烟测试入口
├── core/                    # P1 核心测试
│   ├── auth_test.dart
│   ├── chat_test.dart
│   └── group_test.dart
└── full/                    # P2 全量测试
    ├── contacts_test.dart
    ├── settings_test.dart
    └── edge_cases_test.dart
```

### 2. 核心测试 (Core Test)

**触发条件**: 每日定时构建 (00:00 UTC)

**执行命令**:
```bash
cd frontend
patrol test --target integration_test/core/
```

### 3. 全量测试 (Full Test)

**触发条件**: 手动触发 / 发版前

**执行命令**:
```bash
cd frontend
patrol test
```
