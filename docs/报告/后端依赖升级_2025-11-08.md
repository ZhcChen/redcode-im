## 四、API 适配详情

### 4.1 Redis API 适配

#### 变更 1: 异步连接获取
```rust
// 旧 API
client.get_async_connection()

// 新 API
client.get_multiplexed_async_connection()
```

**原因**: 新版本使用 `MultiplexedConnection` 支持更好的并发性能

#### 变更 2: PubSub 连接创建
```rust
// 旧 API
let conn = client.get_multiplexed_async_connection().await?;
let pubsub = conn.into_pubsub();

// 新 API
let pubsub = client.get_async_pubsub().await?;
```

**原因**: 简化 API,直接从 Client 创建 PubSub

#### 变更 3: 异步查询
```rust
// 旧 API
redis::cmd("PING").query(&mut conn)?

// 新 API
redis::cmd("PING").query_async(&mut conn).await?
```

**原因**: 明确异步/同步 API 区分

---

### 4.2 Axum WebSocket API 适配

#### 变更: Message 类型转换
```rust
// 旧 API
Message::Text(text: String)
Message::Binary(bytes: Vec<u8>)

// 新 API
Message::Text(text.into())    // String → Utf8Bytes
Message::Binary(bytes.into()) // Vec<u8> → Bytes
```

**原因**: 新版本使用更高效的字节类型
