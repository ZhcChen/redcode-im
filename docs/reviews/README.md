# 审查与验证记录目录

本目录用于存放轻工作流 `review` 阶段产出的审查、验证与偏差记录。
在 Codex 中也可通过 `ce:review` 进入该阶段。

## 约定

- 文件命名：`YYYY-MM-DD-<topic>-review.md`
- `TEMPLATE.md` 只作结构参考，不写入真实任务内容
- 小改动可在最终回复中完成 inline review，不强制落文档
- 重要改动、跨模块改动、验收证据复杂或存在残留风险时，应写入本目录

## 内容重点

- 对照计划或目标检查结果是否达成
- 记录已执行验证、关键证据和风险判断
- 明确区分必须修正的问题、可接受残留项和后续建议

## 与其他目录的关系

- `docs/plans/` 提供 review 对照基准
- `docs/reviews/` 保存阶段性审查和验证结论
- 稳定、可复用的经验再沉淀到 `docs/solutions/`
