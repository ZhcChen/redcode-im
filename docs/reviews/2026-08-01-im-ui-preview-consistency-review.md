# IM UI 预览全路由一致性审查

## 审查范围

- 事实来源：`im-ui-html/docs/page-map.md`、`im-ui-html/assets/app.js` 的 `parseRoute()` 与当前 `8020` 运行态。
- 设备：iPhone 12 Pro、iPhone 16 Pro Max、Pixel 8 Pro。
- 状态：正式移动端 demo 深链、空数据壳、无效 ID fallback、Overlay 与输入面板。
- 检查项：顶部导航、背景过渡、内容左右线、Surface、圆角、间距、icon/文字对齐、空/错/加载态和产品外说明文案。

## 路由基线

自动化正式路由清单以 `im-ui-html/tests/routes.ts` 为唯一机器可读来源。设计源入口、规范页、PC 蓝图与 `lab` 属于评审工具，不进入正式移动端回归集合；`#/mobile-design/empty` 作为空数据壳单独检查。

| ID | 严重度 | 固定深链与状态 | 设备 | 证据 | 处理单元 |

## 已稳定基线

- 一级导航固定为聊天、联系人、发现、我的；二级页留在设备壳内。
- 会话操作已采用长按 item 触发，页面不保留三点入口；悬浮菜单只包含业务命令。
- 朋友圈列表与详情共用数量分栏规则，媒体组占满内容宽度。
- 顶部 Quiet Icon、底部导航和主要控件使用至少 `44px` 热区。
- 同页 render 与路由入场已使用不同状态类，后续由 U4 行为测试固定。

## 审查结论

当前视觉语言和信息架构已稳定，不需要继续重设计。后续只处理表内可复现问题，并建立三设备自动化与人工截图证据；新增业务能力转入独立计划。
