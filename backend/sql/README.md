# 数据库变更管理约定

- 当前目录提供 2025-10-20 的全量初始化脚本 `all.sql`，内含目前功能所需的全部结构与基础数据，可在空库上直接执行。
- 自本时间点起，所有数据库结构或基础数据的新增、修改、删除，必须通过新增 SQL 文件记录，不再直接修改已有快照。
- 新增 SQL 文件命名规则：`YYYYMMDDHHMMSS_<简要描述>.sql`（精确到秒，24 小时制，描述使用英文或下划线连接的拼音短语）。
- SQL 文件按时间顺序执行；若需回溯调整，请追加新的更改文件，避免修改历史记录。
- 提交前请确保 SQL 可重复执行（使用 `IF EXISTS` / `IF NOT EXISTS` 等保护语句）并通过本地数据库验证。
