API 概览

RedCode IM 后端API文档，包含完整的用户认证、消息传递和实时通信功能。

服务器信息

  • 基础URL: http://localhost:8080
  • API版本: v1.0.0
  • 数据格式: JSON
  • 字符编码: UTF-8

认证方式

  • 类型: Bearer Token (JWT)
  • 头部: Authorization: Bearer <token>
  • 有效期: 24小时

响应格式

  • 成功: HTTP 200 + 数据
  • 错误: HTTP 4xx/5xx + 错误信息
  • 内容类型: application/json
