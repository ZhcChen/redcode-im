## 🎯 核心功能

### 1. Redis开关控制
- **键名**：`redcode:config:ip_geolocation_enabled`
- **存储**：Redis Session实例（端口6381）
- **默认值**：关闭（key不存在或值为0）
- **开启值**：`"1"`
- **关闭值**：`"0"`

### 2. API端点
```
GET    /api/admin/ip-geolocation/enabled    # 查询开关状态
PATCH  /api/admin/ip-geolocation/enabled    # 设置开关状态
```

### 3. 开关检查位置
- **WebSocket心跳时**（第255行）
- **首次连接时**（第478行）

### 4. 功能行为
| 开关状态 | IP解析行为 | 日志输出 |
|----------|------------|----------|
| 开启（值为1） | 执行解析 | `检测到用户 {id} IP变化` |
| 关闭（值为0或不存在） | 跳过解析 | 无日志（静默跳过） |

## 🎨 设计亮点

### 1. 默认安全
- 开关默认关闭，避免不必要的IP解析
- 符合最小权限原则
- 保护用户隐私

### 2. 实时生效
- 修改开关后立即影响新的WebSocket连接
- 无需重启服务
- 无需重新部署

### 3. 灵活控制
- 通过Redis配置，无需修改代码
- 支持动态调整
- 可在运行时切换

### 4. 资源友好
- 关闭时不消耗任何资源
- 节省API调用额度
- 降低数据库负载

### 5. 完善的监控
- 详细的日志记录
- 开关状态变化可追踪
- 便于问题排查

## 📈 性能影响

### 开关开启时
- ✅ 正常进行IP解析
- ❌ 消耗IPinfo token
- ❌ 增加数据库写入
- ❌ 轻微增加延迟

### 开关关闭时
- ✅ 完全跳过IP解析
- ✅ 零资源消耗
- ✅ 降低处理延迟
- ✅ 提高吞吐量
