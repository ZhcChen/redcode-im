# 数据清理功能修复报告

## 问题概述

### 1. 原始问题
- 数据清理功能报错：`users` 表数据清理后仍然存在
- 添加存储提供商（腾讯云COS）时报错：外键约束违规

### 2. 错误日志分析

#### 错误1：Messages 表自引用外键冲突
```
"room_members_last_read_message_id_fkey" violates foreign key constraint
```

#### 错误2：Storage Providers 外键约束违规
```
"storage_providers_updated_by_fkey" - Key (updated_by) is not present in table "users"
```

## 根本原因

### 1. 清理顺序错误
`messages` 表在 `room_members` 之前清理，但 `room_members.last_read_message_id` 引用 `messages.id`，导致外键冲突。

### 2. 自引用外键未处理
`messages` 表的 `quoted_message_id` 和 `forward_from_message_id` 字段引用自身，导致删除失败。

### 3. 系统数据与用户数据混用
- `storage_providers.updated_by` 字段引用 `users` 表
- 但管理后台的 JWT token 的 `sub` 字段对应 `admin_users.id`
- 数据清理删除了 `users` 表，导致外键约束失败

## 修复方案

### 1. 调整清理顺序
**文件**：`src/handlers/admin.rs` (第4319-4351行)

```rust
// 修复前：
"messages",
"room_members",  // 顺序错误！

// 修复后：
"room_members",  // 先清理依赖表
"messages",      // 再清理被引用表
```

### 2. 清除自引用字段
**文件**：`src/handlers/admin.rs` (第4375-4389行)

在删除 `messages` 表前，先清除自引用字段：
```rust
if table_name == &"messages" {
    sqlx::query("UPDATE messages SET quoted_message_id = NULL, forward_from_message_id = NULL")
        .execute(&mut *tx)
        .await?;
}
```

### 3. 明确清理范围
**文件**：`src/handlers/admin.rs` (第4351-4360行注释)

仅清理用户业务数据，保留系统配置/管理数据：
- ✅ 清理：`users`, `rooms`, `messages`, `feedbacks` 等
- ❌ 保留：`storage_providers`, `admin_users`, `app_versions` 等

### 4. 修改外键约束
**文件**：`sql/migrations/20251201123000_fix_storage_providers_updated_by.sql`

将系统配置表的 `updated_by` 字段改为引用 `admin_users` 表：
```sql
ALTER TABLE storage_providers
DROP CONSTRAINT storage_providers_updated_by_fkey
ADD CONSTRAINT storage_providers_updated_by_fkey
FOREIGN KEY (updated_by) REFERENCES admin_users(id) ON DELETE SET NULL;
```

同时修复的表：
- `app_documents`
- `general_settings`
- `captcha_settings`
- `group_settings.global_mute_set_by`
- `join_requests.reviewer_id`
- `user_roles.assigned_by`

### 5. 改进错误处理
**文件**：`src/handlers/admin.rs` (第4412-4429行)

- 添加 `has_error` 标志跟踪错误状态
- 出错时立即中断并回滚事务
- 返回详细的错误信息

## 完整清理顺序

```
阶段1: 消息相关子表
  message_parts → message_reads

阶段2: 群组管理表
  group_operation_logs → group_mutes → group_admins →
  group_invitations → join_requests → group_rules →
  group_announcements → group_settings

阶段3: 房间成员关系
  room_members → user_room_pins → room_pins

阶段4: 消息表（特殊处理）
  messages (先清除自引用字段)

阶段5: 用户关系表
  user_friend_remarks → friend_requests → friendships →
  user_roles → user_login_history

阶段6: 最终业务数据
  feedbacks → rooms → users
```
