# Bear Chat PC 客户端开发需求文档

## 项目概述

本项目旨在开发一个基于 Tauri 框架的 PC 端聊天工具，将手机版聊天应用（bear-chat-uniapp）的功能移植到桌面端。

## 技术栈

- **前端框架**: Vue.js + TypeScript
- **桌面应用框架**: Tauri
- **构建工具**: Vite
- **包管理器**: Bun

## 核心功能需求

### 1. 用户系统模块
- 用户登录/注册
- 用户信息管理
- 密码修改（登录密码、支付密码）
- 用户权限管理
- 账户余额管理
- 账户交易记录

### 2. 好友系统模块
- 好友列表管理
- 添加/删除好友
- 好友申请处理
- 好友信息更新
- 黑名单管理
- 通讯录同步
- 用户搜索

### 3. 群聊系统模块
- 群聊创建/解散
- 群成员管理（添加/删除成员）
- 群信息设置
- 群权限管理
- 全体禁言设置
- 退出群聊
- 扫码加入群聊

### 4. 消息系统模块
- 单聊消息
- 群聊消息
- 消息撤回
- 聊天记录管理
- 消息状态同步

### 5. 红包转账模块
- 发送红包（单聊/群聊）
- 领取红包
- 转账功能
- 红包领取记录
- 支付密码验证

### 6. 朋友圈模块
- 发布朋友圈
- 朋友圈列表
- 点赞评论
- 删除朋友圈
- 朋友圈更新检查

### 7. AI 聊天模块
- ChatGPT 对话
- 清空聊天记录
- 问题模板
- 文字转图片

### 8. 音乐模块
- 音乐搜索
- 歌曲信息获取
- 歌词显示
- 音乐播放
- 音乐下载

### 9. 文件管理模块
- 文件上传
- 文件下载
- 图片预览
- 文件路径管理

### 10. 实时通信模块
- WebSocket 连接
- 实时消息推送
- 音视频通话
- 在线状态同步

## 移植重点

1. **API 接口移植**: 将 UniApp 的 HTTP 请求接口转换为 TypeScript 实现
2. **状态管理**: 实现类似 Vuex 的状态管理
3. **WebSocket 通信**: 实现实时消息推送
4. **文件处理**: 适配桌面端的文件上传下载
5. **UI 适配**: 将移动端 UI 适配为桌面端界面
