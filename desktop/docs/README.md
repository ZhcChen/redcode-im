## 文档贡献指南

### 命名规范
- 目录名使用中文
- 文件名使用中文，如 `功能分析.md`
- 特殊配置文件保留英文，如 `CLAUDE.md`

### 新建文档
1. 根据内容类型放入对应目录
2. 在本索引文件中添加链接
3. 提交 Git commit

### 文档废弃
1. 移动到 `归档/` 目录
2. 文件名添加 `_已废弃` 后缀
3. 更新本索引
