## 💡 架构优化建议

### 1. **代码组织**
- ✅ 当前结构清晰，API 层设计良好
- ⚠️ 缺少 `composables/` 目录（Vue 3 最佳实践）
- ⚠️ 缺少 `hooks/` 目录（可复用逻辑）
- 建议：添加 `src/composables/` 用于共享逻辑

### 2. **状态管理**
- ✅ Vuex 使用正确
- ⚠️ 可考虑迁移到 Pinia（Vue 3 推荐）
- ⚠️ 缺少持久化插件（vuex-persistedstate）

### 3. **依赖管理**
- ✅ 依赖极简，没有冗余
- ⚠️ 缺少 UI 组件库（考虑 Element Plus / Arco Design）
- ⚠️ 缺少工具库（lodash-es / date-fns）
- 建议：保持当前极简策略，除非确实需要

### 4. **性能优化**
- ⚠️ 缺少路由懒加载（所有页面同时加载）
- ⚠️ 缺少图片懒加载（消息列表图片）
- ⚠️ 缺少虚拟滚动（长消息列表）
- 建议：实现路由懒加载和图片懒加载

## 🔒 安全隐患

### 已识别问题
1. ⚠️ 密码输入未加密传输（应使用 HTTPS + 哈希）
2. ⚠️ Token 存储在 Vuex（应存储在 Tauri 的安全存储）
3. ⚠️ 缺少 CSRF 防护
4. ⚠️ 缺少请求签名验证
5. ⚠️ WebSocket 连接未验证来源

### 建议
1. 实现客户端密码加密（bcrypt/argon2）
2. Token 存储迁移到 Tauri Keychain
3. 添加请求签名机制
4. WebSocket 连接添加 Origin 验证
