# RedCode IM Go 测试工具

这是用 Go 语言重写的 RedCode IM 批量测试工具，具有更好的性能和并发处理能力。

## 项目结构

```
test_go/
├── cmd/
│   └── server0/          # 主程序入口
│       └── main.go       # 主程序
├── bin/                  # 编译输出目录
├── go.mod               # Go 模块文件
├── go.sum               # 依赖校验文件
└── README.md            # 说明文档
```

## 功能特性

1. **并发批量注册**：使用 goroutine 并发处理200个测试账号（手机号从 15396582100 到 15396582299）
2. **智能登录**：如果账号已存在则直接登录，节省重复注册时间
3. **并发好友请求**：所有账号并发向管理员账号发送好友请求
4. **批量处理**：管理员账号自动通过所有测试账号的好友请求
5. **群聊创建**：创建包含所有测试账号的群聊

## 安装依赖

确保你已经安装了 Go 1.19+ 版本。

```bash
cd test_go
go mod tidy
```

## 编译程序

```bash
# 编译到 bin 目录
make build

# 或者直接使用 go build
go build -o bin/server0 ./cmd/server0
```

## 运行程序

```bash
# 运行编译后的程序
./bin/server0

# 或者直接运行
go run ./cmd/server0
```

## 配置说明

- **后端地址**：`BaseURL = "http://localhost:8010"`
- **管理员账号**：`AdminPhone = "15396582900"`
- **群聊名称**：`GroupName = "测试群200"`
- **测试账号范围**：15396582100 - 15396582299
- **并发数**：`MaxWorkers = 10`（最大并发 goroutine 数）
- **密码**：所有账号统一使用密码 `123456`

## 运行流程

1. **并发注册/登录阶段**：使用 goroutine 并发处理200个测试账号（新账号注册，已存在账号直接登录）
2. **并发好友申请阶段**：所有账号并发向管理员账号发送好友请求
3. **审核阶段**：管理员账号批量通过所有好友请求
4. **群聊创建阶段**：创建名为"测试群200"的群聊，并拉入所有测试账号

## Makefile 命令

```bash
make build     # 编译程序
make run       # 运行程序
make clean     # 清理编译文件
make test      # 运行测试（如果有）
```

## 性能优势

- **并发处理**：使用 goroutine 实现真正的并发，比 Python 线程效率更高
- **内存效率**：Go 的内存管理和垃圾回收更高效
- **编译优化**：编译后的二进制文件运行速度快，启动迅速

## 故障排除

如果遇到连接错误：
1. 确保 RedCode IM 后端服务正在运行（默认端口 8010）
2. 检查网络连接是否正常
3. 查看后端日志了解具体错误

如果遇到编译错误：
1. 确保 Go 版本 >= 1.19
2. 运行 `go mod tidy` 更新依赖
3. 检查代码语法是否正确
