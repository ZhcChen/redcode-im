## 🔧 开发命令

### 开发环境
```bash
# 安装依赖
pnpm install

# 启动开发服务器
pnpm dev

# 类型检查
pnpm type:check

# 代码检查
pnpm lint-staged
```

### 构建部署
```bash
# 生产构建
pnpm build

# 预览构建结果
pnpm preview

# 构建分析
pnpm report
```
